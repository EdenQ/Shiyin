Meeting Assistant Install Guide

Meeting notes for macOS: recording, live transcript, speaker identification, AI meeting notes

1. Install

Drag Meeting Assistant from the DMG into the Applications folder next to it.

2. First launch

Meeting Assistant isn’t notarized by Apple, so macOS blocks it the first time you open it, saying the developer can’t be verified or that Apple can’t check it for malicious software. Allow it once:

  1. Double-click Meeting Assistant in Applications. When the warning appears, click Done or OK.
  2. Open System Settings → Privacy & Security and scroll down to Security.
  3. Next to “Meeting Assistant was blocked”, click Open Anyway and enter your password.

If you’re comfortable with Terminal, you can run this instead: xattr -dr com.apple.quarantine "/Applications/Meeting Assistant.app"

3. Welcome guide

On first launch, a short guide walks you through allowing the microphone, downloading the transcription model (about 1.7 GB, once) and choosing a summarizer.

  • Summarizer: if Claude Code (claude) or Codex (codex) is installed and signed in, just pick it. Otherwise enter an Anthropic or OpenAI API key, or choose “Don’t summarize” to get transcripts only.
  • Meeting language: Chinese or English. New meetings use the default from Settings; you can change it for each recording, import or meeting.
  • Global shortcut: press ⌃⌥⌘R in any app to start or stop recording.
  • Online meetings: set the recording source to “Microphone + computer audio (online meetings)”. The first time you record, macOS asks to allow system audio recording; click Allow. If you denied it, turn Meeting Assistant on in System Settings → Privacy & Security → Screen & System Audio Recording.

4. System requirements

  • A Mac with Apple Silicon (M1 or later) running macOS 26 or later
  • 8 GB of memory or more, and about 2 GB of disk space (plus recordings)

5. Privacy

Recording, transcription and speaker identification all happen on your Mac; recordings are never uploaded. When writing meeting notes, only the transcript text is sent to the AI service you choose.

6. Updates

If whoever published Meeting Assistant set an update URL, Meeting Assistant checks for new versions by itself and, after asking you, downloads, verifies and reopens. You can also choose Check for Updates… from the MA menu.

Without automatic updates, download the new DMG and drag the new Meeting Assistant into Applications to replace the old one. Your meetings are kept either way.
