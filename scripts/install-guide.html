會議助手安裝說明

macOS 會議紀錄 app：錄音、即時逐字稿、說話者辨識、AI 會議紀錄

1. 安裝

把 DMG 裡的「會議助手」拖到旁邊的 Applications（應用程式）資料夾。

2. 第一次打開

會議助手沒有經過 Apple 公證，第一次打開時 macOS 會擋下來，顯示「無法驗證開發者」或「Apple 無法檢查是否包含惡意軟體」。請照下面的步驟放行（只要做一次）：

  1. 先在「應用程式」裡雙擊會議助手，看到警告後按「完成」或「好」。
  2. 打開「系統設定 → 隱私權與安全性」，往下捲到「安全性」。
  3. 會看到「已阻擋『會議助手』」，按旁邊的「仍要打開」，再輸入密碼確認。

熟悉終端機的話，也可以執行：xattr -dr com.apple.quarantine "/Applications/Meeting Assistant.app"

3. 首次使用引導

打開後會出現引導，依序：允許麥克風、下載轉錄模型（約 1.7 GB，只需要一次）、選擇整理會議紀錄的工具。

  • 整理工具：已經安裝並登入 Claude Code（claude）或 Codex（codex）的話直接選；沒有的話可以填 Anthropic 或 OpenAI 的 API key，或先選「不整理」只要逐字稿。
  • 會議語言：中文或英文。新的會議用設定裡的預設語言，錄音、匯入時或之後都可以個別改。
  • 全域快捷鍵：在任何 app 裡按 ⌃⌥⌘R 都能開始或停止錄音。
  • 錄線上會議：錄音來源選「麥克風＋電腦聲音（線上會議）」。第一次錄的時候 macOS 會詢問「錄製系統音訊」，請按允許；如果不小心拒絕了，到「系統設定 → 隱私權與安全性 → 錄製螢幕與系統錄音」打開會議助手。

4. 系統需求

  • Apple Silicon（M1 以上）的 Mac，macOS 26 以上
  • 記憶體 8 GB 以上，磁碟空間約 2 GB（加上錄音）

5. 隱私

錄音、轉錄、說話者辨識都在你的 Mac 上完成，錄音不會上傳。整理會議紀錄時，只會把逐字稿文字送到你選的 AI 服務。

6. 更新

發布的人有設定更新網址的話，會議助手會自己檢查新版，詢問你之後自動下載、驗證並重新打開；也可以從「MA」選單選「檢查更新…」。

沒有自動更新時，下載新版 DMG，把新的會議助手拖進「應用程式」取代舊的即可。兩種方式的會議資料都會保留。
